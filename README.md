# 「陪伴·计划」介绍站

给应用「陪伴·计划」做的单页介绍网站。没有构建步骤，没有外部依赖，断网也能打开。

## 怎么打开

直接双击 `index.html`。也可以起一个任意静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

- 右上角按钮在**夜读灯（深色）**和**纸感（浅色）**两套风格之间切换，选择会记在浏览器里。
- 「打开应用」进入 `demo/` 里的一份应用副本，点开就能用。

## 目录

```
companion-intro/
├─ index.html          页面结构与全部文案
├─ styles.css          双主题视觉、响应式、动效
├─ script.js           主题切换 / 页签 / 拐点动画 / 建议小工具
├─ favicon.svg
├─ assets/             应用真实截图（13 张，780×1688）
├─ demo/               应用副本（纯前端，双击 demo/index.html 也能单独用）
└─ tools/
   ├─ shoot.mjs        重新生成 assets 截图的脚本
   ├─ SHOOTING.md      截图流程、每张的状态、失败排查
   └─ qa/              独立验收：qa.mjs / static-qa.mjs / 验收报告.md / shots 截图
```

## 两套主题

- **夜读灯（深色，默认）**：`#14121C` 底 + 紫罗兰 `#8B8BF0`，暖光只出现在和「接回」有关的位置。
- **纸感（浅色）**：`#F3EDE3` 纸底 + 墨色文字 + 深紫 `#5A50C8`。
- 选择存在 localStorage（键 `companion-intro-theme`）。两套都做过对比度检查：关键正文深色最低 4.51:1、浅色 4.72:1。
- 不引用任何外部字体或 CDN；中文大标题用系统宋体族，正文用系统无衬线。

## 页面内容

首屏 → 拐点（计划为什么总在中间断掉）→ 一天里的三件事 → 核心功能与可试的建议引擎 → 界面巡览 → 适合谁 / 不适合谁 → 数据与隐私 → 收尾。

- 文案以应用实际实现为准；冲刺计划截图对应 2026 年 10 月考期（计划期 2026-10-13 起 11 天）。
- 「空余时间建议」小工具是应用规则引擎的简化演示，真实应用读的是用户自己的事项池。

## 关于截图

`assets/` 里的图不是设计稿，是用 headless Chrome 打开真实应用、填入演示数据后截的（390×844，2 倍屏）。想重新生成：

```bash
node tools/shoot.mjs
```

脚本会自己起静态服务、开 headless Chrome、填演示数据、逐张截图。需要本机装有 Chrome；headless Chrome 在 DSH 的 workspace-write 沙箱里起不来（crashpad `OpenProcess: 拒绝访问 (0x5)`），要在没有该沙箱限制的终端里跑。

## 验收记录

- 独立验收（verifier）：静态/逻辑层 **49/49**；浏览器实测 **76/76**（375 / 768 / 1440 三档宽 × 深浅双主题，92 张截图）。
- 覆盖：无横向滚动 / 溢出 / 文字截断、0 控制台报错 / 0 个 4xx、主题切换与刷新记忆、页签点击与键盘、建议工具 6 组组合与空态、锚点导航、`prefers-reduced-motion`、demo 独立运行、`file://` 直开。
- 详见 `tools/qa/验收报告.md` 与 `tools/qa/report.json`；`qa.mjs` / `static-qa.mjs` 可复跑（浏览器脚本同样需要能启动 headless Chrome 的终端）。

## 说明
